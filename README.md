# GrupoHGMAustral S.R.L.

Sitio estático de una sola página, hecho con HTML, CSS y JavaScript sin dependencias.

## Abrir

Abrí `index.html` en cualquier navegador moderno. No hace falta instalar paquetes ni iniciar un servidor.

## Archivos

- `index.html`: estructura y contenido de la página.
- `styles.css`: estilos responsive.
- `script.js`: menú móvil y año del pie de página.
- `assets/logo.jpg`: logo compartido para este sitio.
